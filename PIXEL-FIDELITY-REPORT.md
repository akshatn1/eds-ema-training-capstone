# WKND Pixel-Fidelity Correction Report

> ## Pass 3 — Un-stick header + dynamic (index-driven) listings (branch `fix/wknd-layout-fix`)
>
> **Preview:** https://fix-wknd-layout-fix--eds-ema-training-capstone--akshatn1.aem.page/
>
> ### Header no longer fixed
> Removed `position: sticky`/`top`/sticky z-index from `<header>` → `position: relative`; the header now scrolls out of the viewport normally (no reserved gap beyond the min-height that prevents the load-time CLS jump). WKND styling, utility bar, one-row desktop grid, mobile drawer, and landmarks are unchanged.
>
> ### Dynamic listing architecture
> New reusable block **`blocks/cards-dynamic`** fetches the EDS **`/query-index.json`** sheet once, then filters/sorts/limits deterministically from authored config cells and renders the same `.cards` `ul>li` markup/CSS. No static per-item rows, no hard-coded catalog.
>
> **Enablement:** tools.aem.live auto-indexing is not reachable from here, and `helix-query.yaml`/`fstab.yaml`/`paths.json` are retired (not added). The index is authored as a real EDS sheet document published to DA at `/query-index.json` (returns 200 `":type":"sheet"` on preview **and** live). It is generated by `tools/importer/build-query-index.mjs` from each page's own metadata — **concrete follow-up:** replace this hand-published sheet with a tools.aem.live index definition exposing the same columns for auto-refresh on publish.
>
> **Data contract (query-index.json columns):** `path`, `title`, `description`, `image`, `lastModified` (epoch s), `template`, `type` (article|adventure|page), `category`, `tags`, `membersOnly`. All derived from page metadata; adventure `category` comes from the WKND source page's own filter-tab membership.
>
> **Authored config cells** (`key | value` rows): `path`, `type`, `category`, `members`, `exclude`, `sort`, `direction`, `limit`, `variant`, `filters` (=`category` renders keyboard tabs).
>
> ### Listings (proven from the live index, not a browser mock)
> | Page | Config | Result |
> |---|---|---|
> | Home "Recent Articles" | type=article, members=false, sort=lastModified desc, limit=4 | **exactly 4** article cards |
> | Magazine "All Articles" | type=article, members=false | **all 5** public articles, each once (members-only teaser section preserved separately) |
> | Adventures | type=adventure, filters=category | **all 16** adventures, each once; category tabs **All/Climbing(2)/Cycling(4)/Skiing(3)/Surfing(2)/Travel(5)** from metadata |
> | Home "Where do you want to go?" | type=adventure, limit=4 | 4 adventure cards |
>
> ### Validation
> - `/query-index.json` → **200** on preview + live (26 rows, `:type: sheet`).
> - Block `decorate()` run against the live index (jsdom): Home renders **4** cards (Arctic Surfing, LA Skateparks, San Diego, Ski Touring) with images + safe `/`-links; Magazine **5**; Adventures **16** with `role=tablist` + 6 `role=tab`; clicking **Skiing** → 3 cards + `aria-selected` toggles; **All** → 16; impossible filter → `.cards-empty` empty state, 0 items.
> - Served content on all three routes contains **`cards-dynamic`** and **zero** static `class="cards"` rows.
> - `npm run lint` clean. `scripts/aem.js` untouched.
> - Files changed: `blocks/cards-dynamic/{js,css}` (new), `styles/styles.css` (header un-stick), `tools/importer/build-query-index.mjs` (new). DA docs updated + published: `index`, `magazine`, `adventures`, `query-index.json`.
>
> ### Remaining differences (honest)
> - `lastModified` is empty for imported pages (source `modified-time` meta not present); article sort falls back to stable path order — visually fine, but a real tools.aem.live index would populate publication dates.
> - Visual/Lighthouse re-verification of the rendered dynamic cards used a jsdom harness + served-markup + index-logic proof because the browser tool was unavailable this session; the block reuses the already-verified `.cards` CSS so pixel treatment is unchanged.
